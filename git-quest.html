支援範圍與真實 Git 的差別

純教學模型，提交編號是遊戲流水號，非真正雜湊；初始分支固定 main。只支援根目錄文字檔、單一父提交與快轉合併。不模擬 remote、push、pull、rebase、reset、衝突或 GitHub 登入。切換／合併要求乾淨工作目錄，比真實 Git 更嚴格。diff 以整份舊／新文字呈現，不是正式 unified diff；未追蹤檔不列入 diff。add . 在本練習中涵蓋全部檔案。每檔 6000 字、15 個工作檔、15 分支、80 提交。
