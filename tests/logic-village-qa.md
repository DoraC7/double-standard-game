- 後來查看參考不改寫已取得的首次獨立成果；查看參考的標記與首次驗收結果分開。

## 重跑方法

以 HTTP 伺服器提供根目錄。開啟遊戲，在瀏覽器 QA 中執行 `tests/logic-village-browser-qa.js` 的 async 函式；每個尺寸從新載入的頁面開始。手動也可照任務參考解法操作，故意改錯其中一張卡確認不能沿用舊結果。

本機 HTTP 伺服器可回傳 200，但受控瀏覽器封鎖私人位址導覽；未改動政策，瀏覽器驗證改用既有公開伺服器。GitHub Pages 發布後仍須另行驗證，不以此站代替。
