# 全站冒煙檢查

不需要帳號或付費服務。需 Python 3：在儲存庫目錄執行 `python3 -m http.server 8765`，用瀏覽器開啟 http://localhost:8765/ 。不要用 file://。自動檢查另需 Node.js：`node --test tests/*.test.cjs`。

## 首頁與導覽

- [ ] 桌面 1280×900、窄手機 320×568、橫向 844×390 各看一次：沒有水平截斷，卡片、分類與主要按鈕可到達。
- [ ] 首次開啟顯示全部遊戲；數量與卡片總數一致（目前十一款）。依次按每個分類：只顯示相關卡片、數量正確，選取狀態只標記目前分類；切回全部恢復。
- [ ] 不用滑鼠，以 Tab／Shift+Tab 移動，焦點清楚；Enter／Space 可操作篩選與推薦，Enter 可開卡片。
- [ ] 按「幫我選一款」，依 [推薦視窗 QA](arcade-dialog-qa.md) 檢查開關、重抽與進入遊戲。
- [ ] 開啟先前保存的有效雙標 `#r=` 分享連結：轉到 double-standard.html，保留查詢與片段，仍可讀取結果。

## 逐款入口

每一列都從首頁點入、檢查標題、開始操作並確認無空白頁或錯誤；用遊戲的「遊戲間」連結（若有）或瀏覽器上一頁回首頁，再試下一款。桌面及手機都做；有鍵盤操作的遊戲也試鍵盤。

| 遊戲／檔案 | 開始後應看到／做到 |
| --- | --- |
| 雙標大挑戰 `double-standard.html` | 選模式、讀題並提交選擇 |
| 三秒就忘記 `three-second-forget.html` | 選難度、看物品，倒數後拖放或使用替代操作 |
| 等一下星球 `start-small.html` | 選模式、選一個小步與障礙應對 |
| 多拉甩尾俱樂部 `mini-kart.html` | 開賽，鍵盤／觸控轉向；切分頁自動暫停 |
| 過動大挑戰 `hyper-challenge.html` | 靜音開始暖身，按拍點；切分頁可暫停 |
| ㄅㄆㄇ 小小探險家 `zhuyin.html` | 播放字音、選注音；可返回探索其他玩法 |
| ADHD 日常賓果 `adhd-bingo.html` | 3×3／5×5 切換，勾一格、清除與復原 |
| 龍蝦終端機探險 `terminal-quest.html` | 輸入 pwd，讀取虛擬結果；自由沙盒可切回 |
| 多拉語錄 `dora-quotes.html` | 抽卡、收藏，開始 8 回合接龍；確認喜劇與來源標示 |
| 情緒價值印鈔機 `emotion-printer.html` | 選一種出鈔方式，查看回條及下一單 |
| 龍蝦 Git 時光機 `git-quest.html` | 輸入 git init，再用 git status 查看模擬狀態 |

這是入口冒煙檢查，不代表完整通關。玩法修改仍須依 AGENTS.md 和 tests/ 各遊戲 QA 文件做完整流程。記錄日期、瀏覽器、尺寸、成功項目與未測／失敗項目；開發工具 Console 不應有執行錯誤。
