## 發布前已驗證（2026-10-29）

- 在隔離工作樹 `/tmp/dora-ignorance-challenge` 以 Python HTTP server 的 8765 埠提供候選版本；瀏覽器從既有公開主機名稱連入，非 DOM 預覽。
- `node --check`：案例、引擎、介面、瀏覽器驗證程式皆通過。
- `node --test tests/*.test.cjs`：209 項通過、0 失敗。新增 10 項測試包含 12 案共 36 種資料卡分支、首次結果保留、足夠證據與新時點更新。
- `tests/ignorance-browser-qa.js` 的 `ignoranceQA()` 在 1280×900、360×800、740×390 各通過 1,539 項斷言。
- 每種尺寸各完成六輪：完整局故意每階段錯一次再重試（首次 33/36、最近 36/36）；三輪完整局分別固定選第 0、1、2 張資料卡（各 28/36，合計遍歷所有 36 分支）；快局選無關資料但正確限定結論（8/12）；快局全選先看解析（0/12）。
- 確認前不計分、不揭露資料；確認後全部選項鎖定，重複作答不改結果。重挑資料清除舊卡，後續結論依實際翻開的卡變動。
- 每步檢查水平寬度；三種尺寸無水平溢出。完整結算列出 12 案，快局列出 4 案；重開沒有舊結果。
- 失焦、隱藏分頁、P／Esc 暫停與手動恢復通過；暫停時不可作答或推進，離開暫停畫面可清空回說明。
- 用瀏覽器原生按鍵路徑操作 1、Enter，確認選取與提交；亦檢查 DOM 點選路徑。手機為瀏覽器尺寸模擬，未測實體手機。
- 截圖檢查手機首頁；原創 SVG 正常載入，關閉共用裝飾動畫後仍可開始遊戲；瀏覽器執行期錯誤為 0。
- 點選下載按鈕並攔截下載內容驗證：UTF-8 `text/plain`，檔名「無知大挑戰-本輪紀錄.txt」，包含 4 案原話與 12 步核對及正確分母；單元測試另驗證首次結果不被重試覆蓋。

## 發布後驗收要求

1. 確認部署對應合併後的提交，兩個既有網址都提供新 HTML、CSS、案例、引擎、介面、SVG 與首頁入口。
2. 比較各站檔案位元組與發布候選；主站檔案伺服器另核對實際文件根目錄。
3. 每個站重新導覽，至少桌機與手機直式各執行一次 `ignoranceQA()`，不能把候選版本的結果算成上線驗收。
4. 首頁應有 28 個遊戲入口；篩選及隨機推薦保留，新遊戲在動腦、輕鬆與學習分類皆可見。

## 內容界線

所有人物、氣象、物流、動物、商家與測試紀錄都是虛構模型，不是對群組成員、真實產品或現實事件的判斷。自由推理的能力不能用本輪分數直接認證；本遊戲只核對預先編寫的選擇。不可把尚未翻開的資料當成玩家已知，也不能把有證據的原話擴大改寫後再反駁。
