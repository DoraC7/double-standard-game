# 情緒價值印鈔機 QA

以 HTTP 提供儲存庫根目錄，不使用 file://。自動檢查：`node --test tests/emotion-printer.test.cjs`；全站既有檢查：`node --test tests/*.test.cjs`。

- 從首頁開啟「情緒價值印鈔機」，並確認全部／輕鬆／動腦分類及隨機推薦包含新卡；返回遊戲間正常，舊 `#r=` 轉址保留。
- 1280×900、320×568、844×390 不橫向溢出；主要按鈕可捲動到達。使用 Tab、Enter 操作，焦點清楚，換單後焦點落到新標題。
- 完成 8 單，每單三選一後只能出一張回條；連點不會重複扣款。第 4、8 單有查帳，帳上餘額不為負，Token 不退。
- 在開單時升級金箔，確認後續面額 ×2；費用、心情、查證憑據與查帳率不加倍，不能重複升級。
- 全誠實接話、全查證與混合吹捧路線均可完成。查證只有第 4、6、8 單有附件支持的具體肯定；其他查證仍待證，不能發能力認證。
- 連續吹捧至額度不足時，高成本選項停用，仍保留最低接話額度，不會卡死。
- 結算下載 UTF-8 帳單，內容與流水帳及結算數字一致；重開分行清零；重新整理無儲存狀態。
- 減少動態效果時印鈔動畫關閉，流程不依賴動畫或音效；Console 無執行錯誤；沒有外部網路請求或儲存玩家內容。

數值是虛構遊戲指標，不是真實情緒量表、個人評分、帳單或金錢。
