# Git／終端機指令相容性檢查 — 2026-10-22

範圍：逐項讀過 Git 10 個子指令、終端機 help 列出的全部 14 個入口，以及 10 + 14 關的判定。這是明確列出的教學子集，不是完整 Git／shell 相容性認證。沿用原有 checkout 修正，未新增依賴、後端、持久儲存或網路操作。

## Git

| 入口 | 核對／補上的寫法與語義 |
| --- | --- |
| init | 重複初始化保留資料；初始分支仍固定 main |
| status | 無參數、-s／--short、-b／--branch、-sb；區分未追蹤、已暫存、暫存後又修改；不改環境 |
| add | 單檔、多檔、./檔名、.／./、-A／--all、-u／--update、--；-u 不收未追蹤新檔；先驗證全部路徑再改暫存區 |
| diff | 無參數仍不顯示未追蹤新檔；--cached 與 --staged 等效；不改環境 |
| commit | -m 訊息、-m訊息、--message 訊息、--message=訊息、-a／--all、-am；普通提交不偷收 add 後的修改；-a 只更新追蹤檔，錯誤參數不偷偷暫存 |
| log | --oneline、-n 1／-n1／-1／--max-count 1／--max-count=1；-n0 不列提交，也不能通過需要看提交的關卡 |
| branch | 建立但不切換、--list／-l、--show-current；支援 feature/soup 類名稱；保留原型名稱與數量防護 |
| switch | 既有分支、-c／--create；切換快照與編輯器同步；髒工作區明示教學限制 |
| checkout | 既有分支、-b；與 switch 共用切換事件；不模擬還原檔案、指定起點或 detached HEAD |
| merge | 無選項、--ff-only；僅快轉、重複合併不改資料、不多建提交；分歧時明示尚未模擬三方合併 |

另查 `git --version`／`-v`、`git --help`／`help`，不需先 init；help、clear 不改版本環境。解析器接受引號及跳脫空格，不執行 shell、HTML 或 JavaScript。未知子指令／參數明示為模擬器限制，而非否定真實 Git。

## 終端機

| 入口 | 核對／補上的寫法與語義 |
| --- | --- |
| pwd | 無參數、-L／-P；無符號連結模型，因此結果相同 |
| ls | -a／--all、-A／--almost-all、-l、-h／--human-readable、-1、-la／-al／-lah、多路徑、--；-l 權限／時間明示為模擬資料 |
| cd | 相對／絕對、.、..、~、無參數、--、- 回上個位置；引號或跳脫的 ~ 不展開 |
| cat | 多檔依序串接、--、引號、跳脫空格；不可讀目錄 |
| mkdir | 單／多目錄、-p／--parents 多層與既有目錄、--；不自動進入 |
| touch | 單／多檔、--；既有內容不清空；仍不模擬時間戳記 |
| cp | 單／多來源、目錄目的地、--；來源保留；仍明示不複製目錄、不覆蓋 |
| mv | 單／多來源、目錄目的地、--；來源消失；仍明示不移動目錄、不覆蓋 |
| rm | 單／多檔、--；不遞迴刪目錄，rm -rf 仍不支援 |
| rmdir | 單／多空目錄、--；不可刪非空、目前位置或上層；補入小抄 |
| clear | 只清畫面；資料與匯出紀錄保留，仍需重新 ls 核對 |
| git | --version／-v 等效；只回報模擬版本，不安裝或連接 GitHub |
| uname | 短旗標可合併／重複；對應 GNU 長選項；仍明示虛構系統資訊 |
| help | 全清單、指定入口、未知名稱與原型名稱；不改環境 |

所有多檔改動均採「整條成功才套用」的教學規則，與真實命令可能部分成功不同；UI／README 已明示。空路徑、尾端斜線、檔案作為中間目錄、缺失目錄接 /.. 均檢查。自動補全會跳脫空白名稱，不存在路徑不拋未處理例外。管線、變數、重導向、萬用字元、遞迴操作仍不實作。

## 過關證據

- 保留操作後用讀取指令核對的要求，沒有改成逐字比對固定答案。
- 多路徑 ls／多檔 cat 只要真的讀到指定目標即可核對；看別的路徑不算。
- log -n0 雖是合法讀取指令，但沒有看見提交，不算完成 log 核對。
- 有效等效命令不能因為旗標不同被擋；未模擬的功能明示範圍。

## 學習擴充：Git 16 關／終端機 20 站（2026-10-22）

延續上面的相容性修正，新增 12 關；兩款各有 5 題觀念確認。舊關卡與等效寫法保留。

| 新入口／能力 | 已實作範圍與限制 |
| --- | --- |
| git restore | --staged／-S、--worktree／-W、-SW、多檔、./檔名、.、--；預設從 index 還原工作區，--staged 從 HEAD 還原 index；兩旗標同時指定則從 HEAD 還原兩區。未追蹤新檔保留；未實作 --source。尚無 HEAD 時拒絕 --staged。全部路徑先檢查，不留下部分還原。 |
| git show | HEAD、分支、完整模擬提交 ID；HEAD:檔名、分支:檔名、ID:檔名、:檔名（index）；只讀。無檔名時是教學提交摘要，不是完整 git show diff；不支援 ~、^、縮寫 ID 或選項。 |
| git branch -d | -d／--delete，只刪非目前且已合入目前分支的本地指標；拒絕未合入分支與 -D。無 upstream 模型，不等同真實 Git 所有刪分支情境。提交保留。 |
| find | 單一起點（預設 .）、-type f／d、-name 引號樣式（*／?）；只找路徑、不讀內容；不支援 -exec、-delete、其他表達式或 shell glob 展開。樣式採有界匹配，不執行使用者正規表示式。 |
| grep | 固定文字 -F，搭配 -n／-i／-v／-c、合併旗標、--、多檔與對應長選項；不模擬正規表示式、遞迴或標準輸入。無符合回報非成功，-c 仍顯示 0，不改檔。 |
| head／tail | 單檔、預設 10 行；-n 2／-n2／--lines 2／--lines=2／-2；筆數 0–10000，保留實際行尾。拒絕負數筆數、tail -f、+起始行、多檔與標準輸入。 |

Git 新關卡要求取消暫存／還原的實際事件；雙差異關核對讀取當時的內容，空的或過期的 diff 不算。一般 commit 關區分 auto-stage，收尾需有乾淨 status 證據。Undo／重來／下一關清除本關事件，不能把舊證據帶進新環境。restore 後編輯器同步載入工作區。

終端機新關卡要求真正讀到隱藏檔、保留巢狀副本與來源、找到含空白檔名、讀出兩條帶行號的 ERROR，以及先後讀到開頭與結尾。日誌內容為虛構教學素材，搜尋／成功文字不代表修復或上傳。
