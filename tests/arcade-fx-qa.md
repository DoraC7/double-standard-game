# 遊戲間互動動畫驗收

## 範圍與驗收點

- 大廳：小龍蝦打招呼、心情回覆、分類卡片轉場、滑鼠／鍵盤封面動效、推薦開關與重抽。
- 14 款遊戲：原有入口可玩、明確的題目／回條／數值／結果節點有短動效；不改遊戲腳本、答案、分數、倒數或碰撞。
- 所有頁面：動畫開關不寫入儲存；系統減少動態效果時不產生裝飾動畫；關閉或離開分頁清理執行中的裝飾；不支援 Web Animations 的瀏覽器照常操作。
- 完成動畫只是完成本輪，不判定答案正確；普通回饋只給中性短描邊，不從文字推斷成功。

## 可重現檢查

`node --check arcade-fx.js`；`node --test tests/*.test.cjs`。

桌面 1280×900、窄手機 320×568、橫向 844×390 各檢查首頁與 14 款入口，確認無水平溢出、缺圖與 console 執行錯誤。每款至少操作一個入口／選擇；方向控制、賽車與節拍遊戲確認原暫停仍可操作。完整抽卡接龍與出鈔流程另外檢查結算、重玩。

大廳：Tab 到小龍蝦再 Enter；篩選後按推薦、重抽；Escape 關閉應將焦點還給推薦按鈕。320×568 與短橫向中可捲到 Play，Tab 不逃出 dialog。動畫關閉後重複操作仍應更新文字與結果，但沒有新增動畫。
